# 블로그 리디자인 설계

## 목적

다른 블로그를 참고해 만든 디자인을 "내 디자인"으로 바꾼다. 지금의 분위기(어두운 배경, Gmarket 폰트, 720px 본문 폭)는 유지하고, 포인트 컬러와 정돈된 구분선으로 정체성을 만든다.

## 유지하는 것

- 배경 `#1c1c1c`, 본문 글자색 `rgb(230,230,230)`
- 폰트: GmarketSans Light / Medium / Bold
- 본문 폭: `md:w-medium`(720px)
- 기존 기능: 목차, 읽는 시간, 이전/다음 글, 댓글, 카테고리 필터

## 디자인 토큰

`tailwind.config.js`의 `colors`에 추가한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `accent` | `#ffb86b` | 포인트 컬러 (한 가지만 사용) |
| `line` | `#2e2e2e` | 구분선, 카드 테두리 |
| `muted` | `#999999` | 보조 텍스트 (설명, 날짜, 비활성 메뉴) |

포인트 컬러는 "지금 선택된 것"과 "카테고리"를 표시할 때만 쓴다. 본문 텍스트에는 쓰지 않는다.

## 화면별 변경

### 공통: 헤더 (`components/Layout/Header`)

- 화면 전체 폭 하단 구분선(`line`), 내용은 720px 안쪽
- 로고 `y-baam` 뒤에 포인트 컬러 점: `y-baam.`
- 메뉴(`posts`, `guestbook`)는 Medium 13~14px, 기본 `muted`
- 현재 경로에 해당하는 메뉴는 본문 색 + 하단 2px 포인트 밑줄. `/posts/*`는 `posts` 활성
- 방문한 링크 색(`visited:text-white-300`) 제거

### 공통: 푸터 (`components/Layout/Footer`)

- 회색 배경 띠 대신 상단 구분선(`line`) + `muted` 텍스트

### 홈 (`views/home`)

- 소개 문구 유지, 회전하는 단어("Frontend" 등)만 포인트 컬러
- 오른쪽 링크(github, linkedIn, resume) 뒤에 `↗`, 색은 `muted` → hover 시 본문 색
- 흰 테두리 "Recent Posts" 박스 제거 → 작은 라벨 `RECENT POSTS`(`muted`, 자간 넓게) + 오른쪽 `전체 글 보기 →`(포인트 컬러, `/posts` 링크)
- 최근 글 5개: 행 사이 구분선. 각 행은
  1. `카테고리 · 2026.10.01` (포인트 컬러, Medium, 작게)
  2. 제목 (Medium) — hover 시 포인트 컬러
  3. 설명 (`muted`)

### 글 목록 (`views/posts`)

- 상단 가운데 정렬 "All / N posts" 제거 → 왼쪽 정렬 `Posts` 제목 + 옆에 글 개수(`muted`)
- 카테고리 탭: 하단 구분선 위에 나열, 선택된 탭은 본문 색 + 2px 포인트 밑줄, 나머지 `muted`
- 목록 행 (구분선으로 나눔)
  - 데스크톱(`sm` 이상): `날짜 | 제목 | 카테고리` 한 줄 그리드. 날짜 `muted`, 카테고리 포인트 컬러
  - 모바일: 첫 줄 `날짜 · 카테고리`, 둘째 줄 제목
  - 제목 hover 시 포인트 컬러
- 설명은 목록에서 보여주지 않는다 (홈에서만)

### 글 상세 (`views/posts/post`)

- 카테고리 링크: 포인트 컬러
- 날짜 · 읽는 시간: `muted`
- 날짜 표기: 화면에는 `2026.10.01`로 표시 (데이터와 정렬은 기존 `2026-10-01` 유지)
- 본문 (`markdown-style.module.css`)
  - `h2` 앞에 포인트 컬러 세로 막대(3px)
  - 인라인 코드 글자색: 포인트 컬러 (기존 빨강 `#eb5757` 대체)
  - 링크: 포인트 컬러 + 밑줄 (기존 파랑 `#3498db` 대체)
- 목차: 항목 왼쪽 세로선(`line`), 현재 항목은 본문 색 + 2px 포인트 세로선
- 이전/다음 글 카드: 테두리 `line`, hover 시 테두리 포인트 컬러

### 방명록, 404

- 헤더/푸터 변경이 자동 적용
- 404의 흰 배경 버튼 → 테두리(`line`) 버튼, hover 시 테두리 포인트 컬러

## 날짜 표기

`util/formatDate`를 추가해 `2026-10-01` → `2026.10.01`로 바꾼다. 홈, 목록, 글 상세에서 사용한다.

## 컴포넌트 구조

- `PostItem`(홈과 목록에서 공용) → 홈용 `PostItem`(설명 포함)과 목록용 `PostIndexItem`(한 줄)으로 분리
- `PostHeader`: 목록 상단 제목/개수로 역할 유지, 마크업만 변경
- `Header`: `location.pathname`으로 활성 메뉴 판단

## 하지 않는 것

- 라이트 모드
- 폰트, 배경색, 본문 폭 변경
- 라우팅 구조나 데이터(`posts.json`) 형식 변경

## 확인 방법

개발 서버에서 홈, 글 목록(All과 카테고리 선택), 글 상세, 방명록, 404를 데스크톱(1280px 이상)과 모바일(375px) 폭으로 스크린샷을 찍어 확인한다. 가로 넘침이 없는지, 활성 메뉴와 카테고리 탭 표시가 맞는지, 목차와 이전/다음 글이 그대로 동작하는지 본다.
